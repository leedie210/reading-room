# Development rules

Read README.md and docs/ARCHITECTURE.md before modifying behavior. Personal state stays outside Git. Do not inspect or publish user credentials, databases, media or model files.

Preserve the D reading design and existing preview/export/learning flows. New features require a concrete user request. Maintain source anchors, per-sentence durability, Unicode offsets and edited-note preservation. Use synthetic fixtures and temporary vaults for tests.

GPL-3.0-only applies to project-owned code. Preserve notices for vendor files. Never add proprietary application code, reverse-engineering artifacts or unlicensed dictionary data.
